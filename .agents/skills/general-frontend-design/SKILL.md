# General Frontend Design

Adapted from `anthropics/skills@frontend-design` on skills.sh.

Use this for visual direction. Pair with `neo-ui-product-design` and `neo-sveltekit-svelte5` for this repo.

## Design First

- Decide the product purpose and audience before styling.
- Pick a clear aesthetic direction: refined minimal, industrial, editorial, dense console, soft product, brutalist, etc.
- Make one memorable design choice and execute it consistently.
- Avoid default SaaS sameness: generic cards, pale gradients, random icon grids, and overused hero layouts.

## Craft

- Use typography, spacing, color, borders, shadows, texture, and motion deliberately.
- Keep visual hierarchy obvious.
- Design empty, loading, error, success, and disabled states.
- Make the mobile layout first-class, not an afterthought.

## Accessibility

- Use semantic HTML.
- Ensure focus states are visible.
- Do not rely on color alone for state.
- Keep contrast readable.
- Prefer reduced motion when motion is decorative.

## Shipping Bias

- Build working UI, not mockup-only UI.
- Prefer a cohesive limited system over many one-off styles.
- Preserve the existing app language when the project has one.
